# 使用指南
## 配置环境
按照下方各个官网的指导配置操作系统环境
* [Ubuntu 22.04](https://releases.ubuntu.com/22.04/)
* [Mininet](http://mininet.org/)
* [P4 Language](https://p4.org/)
* [P4Utils](https://github.com/nsg-ethz/p4-utils)

## 启动步骤
- 操作系统：ubuntu 22.04
- 进入`app.py`所在的文件夹（application），在`root`环境下执行：
`python3 app.py`
- 进入本地浏览器,在url中输入`localhost:5000`，进入初始页面
